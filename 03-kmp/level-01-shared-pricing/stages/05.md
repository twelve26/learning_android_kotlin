# M01.5 — Contract evolution

## Concept
commonMain can depend only on APIs available to every declared target. Share business rules and keep platform UI in Android Compose and SwiftUI. Integer cents avoid accidental floating-point money rounding.

## Prerequisites
Kotlin through coroutines/Flow, Android through repositories, and the preceding KMP stages. For level 1, start after the Android repository level; advanced Android can continue alongside this route.

## Mission
Add currency as a domain value and reject mixed currencies; preserve the original tests.

## Observable completion
A mixed-currency cart fails explicitly. Explain binary/API changes.

## Where to work
`shared/src/commonMain/kotlin/Domain.kt` contains `fun totalCents(prices:List<Int>,discountPercent:Int): Long`. Platform integration lives in `shared/src/androidMain`, `shared/src/iosMain`, `androidApp`, and `iosApp/App.swift`. Add focused types rather than accumulating every responsibility in the facade.

## Run
From this project folder:
```sh
./gradlew :shared:testAndroidHostTest
./gradlew :shared:iosSimulatorArm64Test
./gradlew :androidApp:installDebug
open iosApp/LearningApp.xcodeproj
```
Choose **LearningApp** and an iPhone simulator in Xcode, then Run. Read the root environment guide for JAVA_HOME and framework integration. Simulator execution does not require a paid developer account.
