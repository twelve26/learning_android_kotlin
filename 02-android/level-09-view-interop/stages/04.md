# A09.4 — Replace the boundary

## Prerequisites
Complete the previous Android level and its gate. Finish the previous stage in this project.

## Concept in context
AndroidView hosts an existing View inside Compose. factory creates it; update synchronizes changing Compose state. Keep this compatibility lesson isolated from the Compose-first path.

## Build this
Add a Compose progress indicator using the same state, compare behavior, then remove the View in your own branch.

## Acceptance walkthrough
