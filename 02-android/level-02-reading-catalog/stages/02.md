# A02.2 — Search and empty state

## Prerequisites
Complete the previous Android level and its gate. Finish the previous stage in this project.

## Concept in context
Stable IDs connect lists, navigation and detail screens. A back stack is different from a Boolean flag. Keep transient query state saveable and pass IDs rather than full mutable objects.

## Build this
Add case-insensitive trimmed search, a clear action and an empty result message.

## Acceptance walkthrough
