# A05.2 — Delete by identity

## Prerequisites
Complete the previous Android level and its gate. Finish the previous stage in this project.

## Concept in context
SQLite is a durable local store. Put database work on Dispatchers.IO and make schema changes explicit. This lab exposes SQL directly; the extension maps the same contract to Room.

## Build this
Delete a single note by stable ID, including when texts are identical.

## Acceptance walkthrough
Two identical notes can be removed independently; deleting one leaves the other.
