# A01.4 — Accessible completion

## Prerequisites
Complete Kotlin levels 1–5 and environment setup. Finish the previous stage in this project.

## Concept in context
Compose functions describe UI from state. Recomposition reruns descriptions; rememberSaveable keeps small UI values through recreation. Hoist state when more than one component needs it.

## Build this
Add Reset, a polite live region, light/dark previews and a Compose UI test.

## Acceptance walkthrough
