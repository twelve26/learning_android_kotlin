# A03.3 — Lifecycle-aware feedback

## Prerequisites
Complete the previous Android level and its gate. Finish the previous stage in this project.

## Concept in context
A ViewModel outlives Activity recreation and exposes immutable UI state. StateFlow carries current state; collectAsStateWithLifecycle stops collection when UI is inactive. Validation belongs in pure functions.

## Build this
Collect using collectAsStateWithLifecycle and render validation feedback.

## Acceptance walkthrough
Background and foreground the app; state is stable and only one collector drives UI.
