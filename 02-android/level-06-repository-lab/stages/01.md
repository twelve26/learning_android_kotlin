# A06.1 — Repository contract

## Prerequisites
Complete the previous Android level and its gate. Open this project folder in Android Studio and run the starter.

## Concept in context
Constructor injection makes dependencies explicit. Interfaces enable deterministic fakes. Keep domain policy outside Android UI and represent failures as state.

## Build this
Define stock repository and inject an in-memory implementation into a ViewModel factory.

## Acceptance walkthrough
Check stock reports five; creating a new model can use an independent fake.

## Files and contracts
Start in `app/src/main/kotlin/MainActivity.kt` and `Domain.kt`. The domain contract is `fun canReserve(stock:Int,quantity:Int): Boolean`. Read `app/src/test/kotlin/DomainTest.kt` for executable examples. Add files when a responsibility deserves a separate type.

## Run (from this project folder)
```sh
./gradlew :app:testDebugUnitTest
./gradlew :app:installDebug
```
Launch **Repository and dependency injection** from the emulator launcher. For UI tests with a booted emulator:
```sh
./gradlew :app:connectedDebugAndroidTest
```
The supplied UI test checks launch only. Add behavioral tests for the acceptance walkthrough; manual checks are explicitly listed because a launch test cannot prove them.
