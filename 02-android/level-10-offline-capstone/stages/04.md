## Prerequisites
Complete the previous Android level and its gate. Finish the previous stage in this project.

## Concept in context
An offline-first system makes local state the immediate source of truth and treats synchronization as a separate operation. Persist tombstones, identify conflicts and make retries idempotent.

## Build this
Split domain/data/UI modules; add WorkManager outbox drain, fake transport, integration tests, startup measurement and a release build.

## Acceptance walkthrough
Demonstrate offline edit -> relaunch -> retry -> successful sync with no duplicate mutations. Record measured startup and list performance.
