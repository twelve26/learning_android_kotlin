## Prerequisites
Complete the previous Android level and its gate. Finish the previous stage in this project.

## Concept in context
Perform blocking network IO away from the main thread. Distinguish loading, success, empty and failure. The required path uses bundled data and simulated transport failures; a local free server is available for real HTTP.

## Build this
Distinguish an empty response from a failed request. Cancel superseded work or disable duplicate submission.
