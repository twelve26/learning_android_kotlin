# A04.4 — Actual HTTP boundary

## Prerequisites
Complete the previous Android level and its gate. Finish the previous stage in this project.

## Concept in context
Perform blocking network IO away from the main thread. Distinguish loading, success, empty and failure. The required path uses bundled data and simulated transport failures; a local free server is available for real HTTP.

## Build this
Run tools/fixture_server.py and connect with the Android emulator using 10.0.2.2:8765. Add timeouts and close resources.

## Acceptance walkthrough
Server on: three titles. Server off: failure with retry. No account or paid API is required.

## Files and contracts
Start in `app/src/main/kotlin/MainActivity.kt` and `Domain.kt`. The domain contract is `fun parseTitles(text:String): List<String>`. Read `app/src/test/kotlin/DomainTest.kt` for executable examples. Add files when a responsibility deserves a separate type.
